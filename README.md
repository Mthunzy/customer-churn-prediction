# Customer Churn Prediction - Machine Learning

## What is this project?
I built a Machine Learning model to predict which customers will leave a telecom company, so the company can keep them before they leave.

## Business Problem
Losing customers costs a company money. If we can predict churn early, we can offer discounts and save them.

## Skills Used
Python | Pandas | Scikit-Learn | Logistic Regression | Machine Learning

## What I Did
1. Cleaned customer data (missing values, encoded categories)
2. Split data into Train (80%) and Test (20%)
3. Trained a Logistic Regression model
4. Tested accuracy - model predicts with 78% accuracy
5. Found top reasons customers leave: High monthly charges + Short contract

## Key Findings
- Customers on Month-to-Month contracts are 3x more likely to leave
- Customers with high monthly charges churn more
- Fibre Optic users churn more than DSL users
